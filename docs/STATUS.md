# Serpantinum — что сделано (состояние на 18.10.2026)

Система: Gigabyte G5 KF, Arch Linux + Hyprland 0.56.2 (конфиг на Lua), Quickshell 0.3.2, RTX 4060 + Intel Iris Xe,
два монитора: ноутбук eDP-1 и Xiaomi 27" HDMI-A-1. Windows 11 на отдельном SSD.

## Устройство проекта
Исходники — `~/Projects/Serpantinum` (git, https://github.com/Rauan228/arch-hyprland-dotfiles). В систему попадают через symlink'и и скрипты.

| Папка | Что внутри |
|---|---|
| `hypr/` | конфиг Hyprland по модулям: env, monitors, input, look, animations, binds, rules, autostart |
| `third_party/serpantinum/` | неизменённая копия оригинального Serpantinum (AGPL-3.0, коммит 86c3ee2) |
| `overlay/` | наши правки поверх оригинала: точка входа оболочки, диспетчер задач, патчи |
| `config/` | шаблон настроек оболочки, обои (с указанием лицензии) |
| `lock/` | конфиги hyprlock/hypridle (hyprlock — только запасной экран блокировки) |
| `bootloader/` | тема GRUB, записи меню, скрипты установки/отката |
| `sddm/` | тема экрана входа SDDM, установщик, автовход |
| `scripts/` | бэкап, сборка оболочки, link.sh, запуск оболочки, блокировка, клиент `serp` |

Сборка оболочки: `scripts/assemble-shell.sh` → `~/.local/share/serpantinum/runtime` (оригинал + overlay + патчи).

## Hyprland
- Раскладка us/ru, переключение **Alt+Shift**.
- Клавиши: **Alt+F4** закрыть окно, **Win+E** проводник (Dolphin), **Win+V** буфер обмена,
  **PrtSc / Win+Shift+S** скриншот области, **Shift+PrtSc / Win+PrtSc** скриншот экрана, **Win+D / Win+R** меню приложений,
  **Win+C** VS Code, **Win+Return** терминал, **Win+L** блокировка, **Ctrl+Tab** диспетчер задач,
  **Ctrl+Shift+Esc** терминал с fastfetch, Win+1…9 рабочие столы, медиаклавиши и яркость.
- Окна на всю площадь экрана (gaps_out = 0), панели скрываются сами. Размытие стекла усилено (blur 7×3).
- Автозапуск: polkit-агент, hypridle, оболочка Serpantinum, история буфера обмена (cliphist).

## Оболочка (оригинальный Serpantinum на Quickshell)
- Верхняя панель: воркспейсы, музыка, время/дата, погода, трей, раскладка, Wi-Fi, Bluetooth, звук, батарея.
- Док снизу: закреплённые Chrome, VS Code, kitty, Thunar + запущенные программы.
- Обе панели **выдвижные**: появляются, только когда курсор упирается в край экрана (зона 2 px), прячутся через 0,5 с.
  Верхняя при показе сдвигает окна вниз (плавная анимация 0,4 с); нижний док выезжает поверх окон.
- Кнопки окна в правом конце верхней панели: **свернуть / развернуть / закрыть** — для выбранного окна (голубая
  рамка) на любом мониторе; удобно, если промахнулся мимо кнопок заголовка и открыл панель.
- Свернуть как в Windows (`scripts/bin/serp-win min|restore`): «─» в заголовке, кнопка самой программы, док, Alt+Tab —
  всё через один скрипт. Фокус переходит на следующее окно под свёрнутым; вернуть — на тот же стол и то же место
  (развёрнутое остаётся развёрнутым). Состояние: $XDG_RUNTIME_DIR/serpantinum/minimized/.
  Скрытый стол свёрнутых никогда не показывается: если он открылся сам (Hyprland отдал фокус свёрнутому окну или
  программа попросила фокус), оболочка сразу его закрывает (`serp-win special`); окна сами не возвращаются.
- Telegram не выскакивает с фокусом при новом сообщении (правило telegram-no-focus-steal в hypr/modules/rules.lua:
  focus_on_activate = false; правило действует на окна, открытые после него — уже открытому выставляется set_prop).
  Анимация: окно уезжает вниз к доку (середина низа монитора) и растворяется, при возврате вылетает обратно —
  обычные анимации Hyprland. Размер окна не меняется (иначе программы перерисовывают интерфейс под крошечный
  размер). Свёрнутые окна стоят у нижнего края своего монитора (центр окна всегда внутри монитора — по центру
  Hyprland решает, чей это монитор), прозрачны и с no_focus. Скрытый стол не затемняет экран (dim_special = 0).
- **Главный урок:** в Lua-конфиге Hyprland 0.56 тихий перенос окна — `window.move({ workspace = …, follow = false })`.
  Параметра `silent` нет, Hyprland молча его игнорировал: перенос на скрытый стол открывал этот стол, монитор уезжал
  вслед за последним окном, а у окна залипало смещение отрисовки (m_floatingOffset) — Chrome после возврата
  рисовался сдвинутым и заезжал на второй монитор. Настройки анимации на ходу (hyprctl eval) тоже не меняем:
  если менять их посреди движения, оно застывает.
- Все пути сворачивания идут через `serp-win`: «─» в заголовке и в самой программе, Win+↓, Win+M / Win+Home /
  Win+Shift+M (`serp-minall`, QUIET=1 — без анимации каждого окна), диспетчер задач, док, верхняя панель.
- Alt+Tab (и 3 пальца) показывает окна текущего стола и свёрнутые только с него (`serp-win clients` → minDesk).
- Действия `serp-win` идут строго по очереди (flock): двойной клик/касание по доку раньше сворачивал окно посреди
  анимации разворота — запоминалось место под экраном и прозрачность 0, окно потом «не открывалось». Прозрачность
  < 0,2 не запоминается, место вне мониторов — окно встаёт по центру своего монитора. После возврата место и
  размер проверяются (settle).
- Кнопки заголовка — □ ✕ (hyprbars) срабатывают при отпускании кнопки мыши над ними, как в Windows.
- Панель задач по рабочим столам, как в Windows (`dock.runningScope = "desk"`, патч 0009): только окна текущего
  стола на всех мониторах и свёрнутые с него ($XDG_RUNTIME_DIR/serpantinum/minimized.json пишет serp-win).
  Закреплённые значки видны всегда, точка «запущено» — только если окно есть на этом столе.
- Перенос окон между рабочими столами в Win+Tab, как в Windows: зажать карточку окна и перетащить на стол
  в нижней полосе (или на «Создать рабочий стол» — окно уедет на новый); правый клик — меню «Перенести на…».
  Ты остаёшься на своём столе (follow = false). Свёрнутое окно остаётся свёрнутым и развернётся уже на новом столе.
- Курсор сам не прыгает (cursor.no_warps): раньше Hyprland переносил его в окно, которому скрипты отдавали фокус.
  Кнопки заголовка hyprbars запускают команду через executor()->spawn (старый "exec" в Lua-конфиге не работал).
- Меню приложений (приложения / файлы / эмодзи), буфер обмена, уведомления, polkit.
- Обои «туманный лес» на обоих мониторах, цвета интерфейса строит matugen из обоев.
- Запуск `scripts/bin/serpantinum-shell`: одна копия, автоперезапуск при падении.
- Настройки: `~/.config/serpantinum/settings.json` (шаблон — `config/serpantinum/settings.json`).

## Окна как в Windows (hypr/modules/windows.lua)
- Все окна плавающие: их можно класть друг на друга, двигать и менять размер за край; фокус по клику.
- Заголовок как в Windows 11: плоские кнопки **— □ ✕** справа во всю высоту, при наведении подсветка (у ✕ красная).
  Это плагин hyprbars с нашей доработкой на C++ (`hypr/plugins/hyprbars-serpantinum.patch`: button_style, snap_command);
  собирается `scripts/build-plugins.sh` — **после обновления Hyprland запустить снова**. Двойной клик — развернуть.
- «Развернуть» как в Windows (`scripts/bin/serp-max`): окно остаётся обычным, прежний размер запоминается; потянули
  развёрнутое или прилипшее окно — вернётся прежний размер. Режим Hyprland «maximized» сразу переводится в этот.
- **Прилипание при перетаскивании (Aero Snap):** к левому/правому краю — половина, к верху — развернуть, в угол —
  четверть; пока тащите — подсветка будущего места. Края между мониторами не считаются. (`serp-snapzone`)
- **Snap Assist:** после прилипания в свободном месте — остальные окна с живыми миниатюрами, клик ставит окно туда.
- **Win+Z — раскладки (Snap Layouts):** 2 половины, 2/3+1/3, 3 колонки, половина + 2 четверти, 4 четверти,
  широкая середина; клик по месту ставит окно, дальше Snap Assist для остальных мест.
- Win+←/→ — половина экрана (у края — на соседний монитор), Win+↑ — развернуть, Win+↓ — восстановить/свернуть,
  Win+Shift+←/→ — на другой монитор, Win+M — свернуть все, Win+Shift+M — вернуть, Win+Home — свернуть все кроме
  активного (`serp-snap`, `serp-minall`). Win+M больше не завершает сеанс (это было опасно).
- Программы запоминают размер и место (`serp-geom`, ~/.local/state/serpantinum/geometry.json) и открываются там же.
- Окна не «улетают», развёрнутые окна, запоминание мест — один постоянный процесс `serp-windowd` (слушает
  события Hyprland, ходит в него через сокет; ~1% ядра, 14 МБ). Раньше на каждое событие запускалась связка
  serp-fit → serp-max check → serp-geom save (~100 процессов, ~20 запросов к Hyprland) — при нескольких
  рабочих столах это давало подтормаживания. В простое теперь ~1 процесс/с (было 13–49). Размытие 2×8.
- Док как панель задач: клик по активному приложению сворачивает его; при наведении — миниатюры окон (✕ — закрыть).
  Правый клик — меню приложения, миниатюры при этом прячутся и не перекрывают меню.
  Клик по значку приложения — `serp-win taskbar` (патч 0007), как в Windows: окна текущего стола (и свёрнутые
  с него): одно активное — свернуть, несколько — следующее, иначе последнее использованное; на этом столе нет —
  переход к последнему на другом. Клик по миниатюре — `serp-win focus` (патч 0003, WindowTracker): свёрнутое
  разворачивается; окно на другом рабочем столе — сначала стол переключается на всех мониторах сразу (раньше
  переключался один монитор и столы «расходились»); затем фокус и поверх остальных (одного фокуса мало).
  Значки запущенных программ стоят на своих местах, новая программа — в конец (патч 0008; раньше порядок
  пересобирался при каждом сворачивании/фокусе и значки убегали из-под курсора).
  Проверено настоящими кликами виртуальной мышью (/dev/uinput) и жестами виртуального тачпада.
- Жесты тачпада: 3 пальца влево/вправо — Alt+Tab: сразу появляется окно со всеми окнами, каждый свайп двигает
  выбор, через ~0,8 с после последнего выбранное открывается (`ipc call switcher swipe`); 4 пальца — соседний
  рабочий стол на всех мониторах (`serp-desk`).
- Переключение рабочих столов — как в Windows: стол уезжает в сторону, следующий въезжает справа (~0,3 с,
  кривая deskSlide в hypr/modules/animations.lua); скрытый стол свёрнутых окон — без анимации.
- Курсор Windows (`scripts/install-cursor.sh`, тема Windows-10 в ~/.local/share/icons).
- Мышь как в Windows: кривая ускорения «Повышенная точность» из реестра Windows (`hypr/modules/input.lua`,
  MOUSE_SPEED — скорость, MOUSE_WIN_ACCEL=false — без ускорения 1:1). Тачпад — обычный libinput.

## Alt+Tab и рабочие столы (overlay/quickshell/switcher, scripts/bin/serp-desk, hypr/modules/desktops.lua)
- Alt+Tab как в Windows 11: тёмная панель, миниатюры в пропорциях окон, значок и заголовок, белая рамка у выбранного,
  ✕ — закрыть; Delete — закрыть выбранное, Esc — отмена, отпустить Alt — перейти (свёрнутые разворачиваются).
  Ctrl+Alt+Tab — «липкий» режим (не закрывается при отпускании Alt; стрелки + Enter).
- Win+Tab — «Представление задач»: окна стола (клик — перейти, ✕ — закрыть, правая кнопка — перенести на другой стол)
  и полоса рабочих столов: перейти, закрыть (✕), «+ Создать рабочий стол».
- Рабочий стол N = пространство N на ноутбуке + 100+N на HDMI: переключаются оба монитора сразу.
  Win+Ctrl+D — новый, Win+Ctrl+←/→ — листать, Win+Ctrl+F4 — закрыть (окна переезжают на соседний),
  Win+1…9 — перейти, Win+Shift+1…9 — перенести окно, Win+Ctrl+Shift+←/→ — перенести окно и перейти, Win+колесо — листать.
- При смене стола сверху появляется подсказка «Рабочий стол N»; кружки на верхней панели — это столы.

## Скриншоты (как Lightshot, наш код `overlay/quickshell/snip`, запуск `scripts/bin/serp-shot`)
- PrtSc / Win+Shift+S: экран замирает, выделяете область (рамка с ручками, размер в пикселях, перенос и растягивание).
- Справа инструменты: карандаш, линия, стрелка, прямоугольник, маркер, текст, цвет, отмена (Ctrl+Z); толщина — колесом.
- Снизу: копировать (Ctrl+C / Enter), сохранить (Ctrl+S → `~/Pictures/Screenshots`), закрыть (Esc / правая кнопка).
- Работает на любом мониторе: экран замораживается на всех, выделять можно там, где курсор.
- Ctrl+A — весь монитор под курсором. Shift+PrtSc — весь экран сразу в буфер и в папку.
- Загрузки в интернет (prnt.sc) нет — снимки никуда не отправляются.

## Окно музыки (клик по музыке на верхней панели)
- Плеер (MPRIS через playerctl): перемотка, пауза, назад/вперёд; визуализатор вокруг обложки — cava.
- Текст песни — из интернета (lrclib.net, NetEase); у редких треков (slowed/ремиксы) текста может не быть.
- Эквалайзер, пресеты и вкладка «Аудио» (баланс, моно, перестановка каналов, динамика) — через EasyEffects:
  `sudo pacman -S --needed easyeffects lsp-plugins-lv2 calf`, затем `scripts/setup-equalizer.sh`
  (служба `config/systemd/ee-eq.service` — EasyEffects в фоне с пресетом live_eq).

## Игры на втором SSD (Kingston A2000 1 ТБ, там же Windows)
- Linux — на Gigabyte 512 ГБ (PCIe 4.0), игры — на отдельном разделе ext4 «Games» второго SSD (PCIe 3.0): FPS и
  графика от диска не зависят, загрузки — секунды разницы. NTFS-раздел Windows для Steam под Linux не используем
  (Valve не рекомендует: права, имена файлов, Proton, «Быстрый запуск» Windows).
- Шаг 1 — в Windows сжать том C: («Управление дисками»); шаг 2 — `sudo scripts/setup-games-disk.sh` (берёт только
  неразмеченное место, разделы Windows не трогает) → /mnt/games, папка Steam `/mnt/games/SteamLibrary`.

## Программы
- `scripts/install-apps.sh` — Telegram, WhatsApp (ZapZap), Steam, Spotify (spotify-launcher), Discord, Antigravity, Obsidian.
  Включает [multilib] в /etc/pacman.conf (с копией в /var/backups) и ставит 32-битные драйверы для Steam.

## Экран блокировки
- Оригинальный экран Serpantinum: размытый фон и часы → по клавише панель с погодой, CPU/RAM/температурой,
  диском, сетью, аватаром, паролем, раскладкой/батареей, уведомлениями и плеером.
- Наш патч: первая клавиша только открывает панель и в пароль не попадает.
- Пароль проверяет PAM. Автоблокировка через 10 минут (hypridle), перед сном экран блокируется.
- Если оболочка недоступна — запасной hyprlock.

## Диспетчер задач (Ctrl+Tab, наш код)
- Оформление: тёмное стекло с бирюзовым акцентом, боковое меню, поиск, кнопки окна, карточки ЦП/Память/Диск/Сеть/ГП
  с мини-графиками, таблица с «тепловой» подсветкой.
- Вкладки: Процессы, Производительность (ЦП по ядрам, память, диски, сеть, Intel и NVIDIA), Журнал приложений
  (время ЦП, время работы), Автозагрузка, Пользователи, Подробности, Службы, Параметры (частота обновления,
  стартовая вкладка, группировка — сохраняются в `~/.config/serpantinum/taskmgr.json`).
- Действия: снять задачу, KILL, режим эффективности (nice 10, листок в «Состоянии»), приостановить/возобновить,
  открыть расположение, копировать PID, новая задача, управление службами через pkexec.
- Системные процессы подписаны понятными русскими названиями с иконками (`taskmgr/names.js`).
- Реальные данные из /proc, /sys, DRM fdinfo (загрузка ГП по процессам), hyprctl, nvidia-smi.
- Ограничение Linux: сеть по процессам без прав root недоступна — сеть показана только суммарно.

## Вход в систему
- При включении: автовход SDDM за rauan → оболочка сама блокирует экран тем же экраном, что Win+L
  (страховка: hyprlock, если за 20 с блокировки нет). Включение/выключение: `sudo sddm/autologin.sh [--off]`.
- При выходе из сессии — экран входа SDDM с нашей темой (три колонки, реальная погода, аватар).

## Меню выбора ОС (GRUB)
- Тема по референсу: стеклянная панель, логотип, две плитки в ряд, голубое свечение выбранной.
- Пункты: Arch (своя запись на UKI), Windows 11 (chainloader на ESP Windows), «Резерв» (штатный uki).
- Клавиши: ↑/↓ и Enter, **A** — Arch, **W** — Windows (←/→ GRUB не поддерживает).
- `os-prober`, пункты «EFI BootNext» и «UEFI Firmware Settings» отключены.
- Не трогали: grub-install, EFI-загрузчики, BootOrder, разделы, Windows.

## Звук и чёткость программ
- Звук: PipeWire + WirePlumber; для работы звуковых карт и Bluetooth доустановлены pipewire-audio, pipewire-alsa,
  pipewire-pulse, rtkit (без них в системе не было ни одного аудиоустройства).
- Electron-программы (Discord, Obsidian, Antigravity) работают нативно через Wayland: `ELECTRON_OZONE_PLATFORM_HINT=auto`
  в hypr/modules/env.lua. Spotify — флаги Wayland в `config/spotify/spotify-launcher.conf` (→ ~/.config).
  Без этого на экране ноутбука (масштаб 1.5) они шли через XWayland и выглядели пиксельными.
- Перезапуск оболочки: `scripts/restart-shell.sh` (запускает её через Hyprland с окружением сеанса).
